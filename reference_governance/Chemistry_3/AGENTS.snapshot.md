## 6. Terminology & High-Priority Corrections

Use `n/mol`, `M(B)/g/mol`, `c(B)/mol/L`, `w(B)` with percent basis, `γ(B)/g/L`, and `ρ` for density. Course `M` as mol/L is an exam convention and must be mapped explicitly. Distinguish solute/solvent/solution denominators; never infer percent kind, volume additivity, density, full dissociation, or 1:1 neutralisation.

## 7. Design & CSS Engineering Standard

Layer order: `reset, tokens, base, layout, components, utilities, print`; primitive → semantic → component tokens; 60–75ch text measure; intrinsic layout, fluid `clamp()`, visible `:focus-visible`, 44×44 CSS px targets, reduced-motion support, 390px no-clipping, SVG text ≥12px, ≥4.5:1 text and ≥3:1 large/UI contrast on resolved backgrounds. Print expands details without JS where supported, underlines references, repeats table heads, avoids split rows; PDF target is zero Type 3 fonts, chapter outline, tags or dated limitation. Anti-slop: no gradients/glow/glass, decorative shadows/animation, structural emoji, hero banners, fragmenting card grids, tracked uppercase labels, invented metrics, or color-only meaning. Source/DOM checks are not visual proof.
