## TERMINOLOGY-DICTIONARY

The list below carries the current source-ledger decisions. Rows marked `[apstiprināt]` are editorially open, not official nomenclature.

| Preferred form / notation | Avoid or distinguish | Rule / evidence |
|---|---|---|
| *vielas daudzums* *n*; unit mol (*mols*) | “molu skaits”; mol as quantity | Quantity differs from unit. |
| *relatīvā atommasa* *A*ᵣ; *molmasa* *M* (g/mol); *masas skaitlis* *A* | one name/symbol for all | E05; isotope-specific `N = A − Z`. |
| *formulvienība* for ionic solids | “NaCl molekula” | Ionic crystal is not molecular. |
| NH₃(aq) / NH₃·H₂O | NH₄OH as discrete compound | E27; write equilibrium explicitly. |
| *oksidēšanas pakāpe* `[apstiprināt]` | *oksidēšanās pakāpe* mixed in; ion charge; valence | Charge `Fe³⁺`; oxidation state `+3` or `(III)`. |
| *oksidētājs* (reducējas); *reducētājs* (oksidējas) | oxidizer “oxidizes” itself | Agent accepts/donates electrons. |
| *normālie apstākļi* with temperature and pressure | bare “n.a.” with 22,4 | E60; state adopted convention. |
| *reakcijas veids / klasifikācija* | *reakcijas mehānisms* for type labels | E41; mechanism means a stepwise pathway. |
| *piesātināts*, *nepiesātināts*, *pārsātināts* | *koncentrēts*, *atšķaidīts* as synonyms | Solubility state differs from concentration. |
| *masas daļa* *w*; *molārā koncentrācija* *c(X)* (mol/L); *blīvums* ρ | “CM”, “procentuālā koncentrācija”, normality | Course notation; do not introduce normality. |
| *hidratācija/solvatācija*; *kristālhidrāts*; *hidrolīze* | “hidrāts” for all | Distinct solution-shell, crystal and reaction concepts (E24). |
| *elektrolītiskā disociācija* | conflate ionic dissociation with molecular ionization | Course umbrella term; explain difference in depth. |
| *bāze*; *sārms* (water-soluble base); *hidroksīds* (compound class) | use as synonyms | NH₃ is a base without OH. |
| *bāziskais oksīds*, *bāziskā vide*, *bāziskais sāls* | same meaning for each | Course uses *sārmains* for pH > 7. |
| *skābais sāls* (replaceable H) | “skābs šķīdums” | NaHCO₃(aq) can be alkaline. |
| *skābes atlikums* | — | Anion in course usage. |
| *amfotērs* (oxide/hydroxide); *amfolīts* / *amfiprotisks jons* `[apstiprināt]` | one word for both | e.g. Al₂O₃ vs HCO₃⁻. |
| *ūdeņraža saite*; describe as intermolecular/intramolecular interaction | universal “starpmolekulārā saite” | E13; not a covalent bond. |
| *atomu (kovalentais) kristālrežģis* `[apstiprināt]` | *atomārs* for diamond/Si | Distinguish monatomic particles (E15). |
| *hlorūdeņradis* (gas); *sālsskābe* (aqueous HCl) | merged phase names | State phase accurately. |
| ion charge `Fe³⁺` (magnitude then sign) | `Fe⁺³` | Oxidation state is written `+3` or `(III)`. |
| decimal comma; thin no-break space before units; `L`; U+2212 minus; upright `pH` | decimal point, lowercase l, hyphen-minus | Chemistry typography contract. |
| italic *n, m, M, V, c, ρ, α, K*; upright units, element symbols, formulae | mixed notation | Follow SI/Green Book convention; exact edition remains to verify. |
| English glossary equivalent | unsupported etymology | Add only when independently verified. |
