<a id="four-language-stack"></a>
## [FOUR-LANGUAGE-STACK] Allowed languages and build boundary

| Tier | Language | Contract |
|---|---|---|
| 1 | Semantic HTML5 + modern CSS | ≥95% interactive/visual behavior; native details/dialog/popover and CSS state/layout; offline and useful without JS |
| 2 | Python 3 | Deterministic extraction, computations, static tables/indexes/SVG coordinates, contrast, anchors, lint and budgets before browser open; final HTML has no external runtime dependency |
| 3 | TypeScript | Residual client logic only when HTML/CSS and Python cannot perform it; `strict: true`, zero `any`, explicit DOM null checks; compiled/minified output only |
| 4 | Raw JS | Compiled Tier-3 micro-runtime only; registry-listed and budgeted; no primary UI architecture |

Canonical Python invocation pattern: `python3 -I -B tools/<name>.py [args]`; standard library only unless an approved source-extraction tool is explicitly needed during authoring. Non-zero exit on failure. SKIP never counts as PASS. Final HTML is one offline file with inline CSS/JS/SVG, system fonts, no CDN, web fonts, remote images, `fetch`, `@import`, MathJax, storage, cookies, `eval`, or network request.

<a id="js-suppression"></a>
## [JS-SUPPRESSION] Hard budget and forbidden behavior

Executable inline `<script>` content must satisfy all limits: ≤6,096 bytes, ≤100 formatted lines, and ≤2% of the HTML byte size. Effective ceiling is the minimum. (Owner K6 ruling 2026-11-12: byte ceiling raised from 4,096 B by +2,000 B; lines and share unchanged.) Zero inline event-handler attributes; any handler ≤60 lines. Ban `innerHTML`, `outerHTML`, `insertAdjacent*`, `document.write`, `createElement`-based templating, data-array-to-HTML hydration, JS accordions/tabs/modals/tooltips/theme/reveal, scroll-jacking, decorative `requestAnimationFrame`, external libraries/frameworks. JS outside the registry or budget is `[JS-BLOAT]`. Maximum four instruments, of which no more than three can be JS-driven; no fifth widget.

Since T15 (2026-11-12) this is machine-enforced end to end: `tools/compile_ts.mjs` compiles `src/ts/` with the pinned compiler and refuses budget overruns; `tools/verify_js.mjs` scans the built HTML (ceilings, registry allowlist `$ fmt upd num s2` with exactly three `upd`, banned APIs and unregistered feature tokens raw-scanned so string-hidden regressions fail; `--selftest` 5/5); `tools/budget.py` gates B1–B12 read-only (`--selftest` 14 negatives + positive control) as run.sh step 2d; verify.py C19/C21 updated to the same contract.
